# Bewegungslabor · Physik EF

Lernseite zur gleichmäßig beschleunigten Bewegung für die Einführungsphase:
Theorieteil mit den drei Bewegungsgleichungen und zwölf Sachaufgaben in vier Stufen
mit Selbstkontrolle.

- Eine `index.html`, Bilder in `bilder/` (WebP). Keine fremden Dienste, nichts wird nachgeladen.
- Der Bearbeitungsstand liegt im Browserspeicher (`localStorage`) des Geräts.
- Die Seite läuft per Doppelklick oder über einen Webserver.

Live: https://dm-pkg.de/bewegungslabor/
